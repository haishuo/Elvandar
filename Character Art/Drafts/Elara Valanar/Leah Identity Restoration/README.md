The selected calibration changes are localized edits of the existing plates. Crown positions, soles and
relative scale were visually compared against those originals; this pass does not certify new deterministic
measurements. The master fitting frame is unchanged. The rejected rebuilt plate is kept only as a draft.

Tiberian and Melina preserve their established distinct inheritance patterns and ages. Tiberian's solo and
plate remain age sixteen; At the Taps is approximately eighteen. Neither child's revised face changes the
written measurements. Existing unrelated characters were retained as reference constraints in shared scenes.

All files in Superseded are historical references only and must not supply Elara's face for new work.
Retired illustrations and earlier complexion-correction archives remain untouched.
