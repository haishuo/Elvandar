# Character Art — Visual Index

This directory is the visual archive for the series. Raster files are deliberately untracked by Git and
mirrored to Backblaze B2 under `elvandar/Character Art/`; this index is tracked so the organization,
authority and intended use of the images remain visible in the repository.

Art is downstream of canon. An approved image can preserve an explicit authorial visual ruling, but an
image does not establish a prose fact merely because it depicts one convincingly. `People/Basic Physical
Characteristics.md` remains the authority for fixed measurements and physical traits.

## How to use the reference models

1. **Height-calibration plates are the primary “T-pose” models.** Use them to anchor identity, exact height,
   body scale and relative proportions when composing new images.
2. **Photorealistic solo models supplement facial, clothing and texture detail.** They may be used beside a
   calibration plate, but they do not override its scale.
3. **Group references establish relative scale and shared identity.** They are useful when more than one
   established character appears in a new image.
4. **Scene art is not a default model sheet.** Use an earlier scene as a reference only when the requested
   result is specifically a remake, edit or continuation of that scene.
5. **Alternate-universe images never establish canon.** Their containing folder carries the non-canon
   status, so individual filenames do not repeat it.
6. **Build height plates with the white-background composite pipeline.** First generate the character alone,
   standing naturally in normal clothing against a pure, evenly lit white background. Use a neutral frontal
   pose with the whole body and both feet visible, no scenery or floor clutter, and no more than a faint
   contact shadow. Second, cut out the figure and composite it onto the immutable master fitting-frame room,
   scaling and positioning it deterministically: boot soles on the brass heel line and crown at the exact
   ruler coordinate. Third, use AI image editing only to repair cutout edges, contact shadows, lighting seams
   and other compositing artifacts while preserving the approved identity, clothing, pose and frame geometry.
   Recheck crown and heel positions after cleanup; an attractive plate with shifted geometry is rejected.

## Naming rules

- Let the folder carry medium, purpose and canon status; do not repeat them in every filename.
- Name reference models by character and scenes by event.
- Replace `v2`, `final` and similar suffixes with a description of what actually differs.
- Preserve superseded but useful generations under `Drafts/`; do not mix them with approved models.
- Add every new raster asset to this index when it is archived.

## Storage and synchronization

The local raster files are ignored by Git. Their durable copy lives in Backblaze B2, with remote paths
mirroring this directory. From the repository root:

```text
./Tools/sync_art.sh status
./Tools/sync_art.sh verify
./Tools/sync_art.sh push --yes
./Tools/sync_art.sh pull --yes
```

The standard push operation copies new and changed objects but does not delete obsolete remote paths. A
future structural migration must therefore upload and verify the new layout before old B2 paths are removed.
