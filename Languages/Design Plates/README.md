# Language Design Plates

Design plates are the linguistic equivalent of character-image iterations. Each plate is a complete,
coherent proposal meant to be judged by ear, texture, expressive range, and fit with the people who speak
it. A plate is not canon merely because it is detailed.

## Rules

- Build from culture and history, not from the current name list.
- Build around P0 forms, treat P1 as strong but defeasible evidence, and do not use P2–P4 forms to select
  sounds, affixes, roots, or naming patterns.
- Test a plate first with newly coined words, names, and sentences.
- Mark the plate **working**, **rejected**, or **approved**. Only the author can approve one.
- Do not merge an unapproved plate into the canonical language files.
- After approval, compare it with `../Attested Forms Register.md`. P0 forms receive whatever historical
  accommodation is necessary. P1 forms receive a strong presumption of survival but never force a
  contorted system. P2–P4 forms have no design authority and must earn survival naturally.

Rejected plates stay here because they record useful aesthetic decisions: what sounded too soft, too
ornate, too familiar, too regular, or simply unlike the intended people. They have design-history value
and no canon authority.
